# 🚗 BMW Sales Analytics

## 📊 Project Overview

BMW Sales Analytics is an end-to-end data analytics project developed to analyze **6,000 BMW sales transactions** and identify meaningful business insights.

## 🎯 Objectives

- 📈 Analyze BMW sales performance
- 🚘 Identify top-performing BMW models
- 🌍 Compare sales across cities and regions
- ⛽ Analyze different fuel types
- 👥 Analyze customer segments
- 🛒 Analyze sales channels
- 📅 Track monthly sales trends
- 💰 Analyze revenue, discounts, and net sales

## 🛠️ Tools & Technologies

- 🐍 **Python**
- 🐼 **Pandas**
- 🐘 **PostgreSQL**
- 🗄️ **SQL**
- 📊 **Microsoft Excel**
- 🔄 **PivotTables**
- 📈 **PivotCharts**
- 🎛️ **Excel Slicers**

## 🔄 Project Workflow

1. 📥 Generated and prepared BMW sales data
2. 🗄️ Stored the data in PostgreSQL
3. 🔍 Performed SQL-based analysis
4. 🧹 Cleaned and validated the dataset using Python and Pandas
5. 🔎 Checked missing values and duplicate records
6. ✅ Validated revenue, discount, and net sales calculations
7. 📊 Created an interactive Excel dashboard
8. 💡 Presented KPIs, trends, and business insights
